Dynamic Form Field Analytics Portal

Find the exact checkout field that slows customers down, without ever recording what they type.

Try the checkout form Open the dashboard
1Capture

A small script listens for focus, blur, input, validation errors and corrections on each field.

2Validate & store

A Flask API checks every event against an allowlist and stores it in SQLite.

3Analyse

Visits, time per field, error, correction, progression and drop-off rates are calculated.

4Improve

The dashboard ranks fields so the team knows which one to fix and re-test first.

What is collected

Stored

  • Field identifier (e.g. postal_code)
  • Event type and timestamp
  • Random session token
  • Coarse device and browser category
  • Validation error category (required / format / length)

Never collected

  • Anything typed into a field
  • Names, emails, phone numbers, addresses
  • Card number, CVV or any payment field (not instrumented)
  • IP address or full user-agent string
